# --- Requires approval per use -----------------------------------------
#
# Not filler in the way the rest of this list is: the word is fine in
# ordinary English. It is here because it had become a verbal tic across
# both repositories -- "the honest word", "the honest complication", "the
# corpus that keeps them honest" -- where it was doing no work that the
# surrounding sentence was not already doing. Four uses were removed
# upstream the day the line was added, and two more here: zig/README.md
# and zig/DOCS.md both called a divergence "the honest answer", which is
# the sentence flattering itself rather than describing the divergence.
#
# There is no inline exemption for it, deliberately: an escape hatch that
# exists gets used. A use the author wants kept is approved by editing
# this line, which is visible in review.
honest(y|ly)?
